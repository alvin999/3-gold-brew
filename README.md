# ☕ 3 Gold Brew

> **「精準、節奏、極致效率。」** —— 專為追求頂尖沖煮表現而生的咖啡練習與計算工具。

---

## 📖 命名的由來

**3 Gold Brew** 的靈感來源於兩個富有象徵意義的主題：

1.  **大禹治水**：「三過家門而不入」，象徵著專業咖啡師對於技術磨練、對細節堅持的一心不亂，以及在繁忙吧台後面的勤奮奉獻。
2.  **沖煮賽精神**：在 **WBrC (World Brewers Cup)** 沖煮大賽中，選手必須在 **10 分鐘內** 展演並呈送出 **三杯「金沖煮」** 咖啡。這不僅是技術的對決，更是時間管理與沖煮節奏的極致考驗。

本專案旨在提供一個數位環境，讓您能像賽事選手般精準控制每一秒、每一克。

---

## ✨ 核心功能

### 1. 智慧節奏計算機 (Smart Tempo Calculator)
- **多杯連發計算**：自定義沖煮杯數與配方比例，系統將自動演算最優化的沖煮時間軸與節奏提醒。
- **動態節奏生成**：根據您的沖煮模式，即時生成可視覺化的時間刻度。後

### 2. 吧台訓練效率工具 (Barista Training Simulator)
- **沈浸式 3D 模擬**：結合 Three.js 打造的 3D 沖煮空間，讓您在虛擬環境中練習多工處理能力與出杯手感。
- **效率優化**：透過重複練習，找出最適合您的動作路徑，大幅提升實戰吧台的作業效率。

### 3. 動態參數調整計算機 (Pulse Pouring Calculator)
- **臨時方案救星**：沖煮現場常常需要臨時微調。無論是更改粉量 (Grounds) 還是調整斷水次數，系統都能瞬間幫您精算出每一段的最佳注水量與比例。
- **斷水比例視覺化**：直覺地查看每一注水份段的占比，確保風味的可重複性。

## 🛠️ 技術棧 (Tech Stack)

- **3D 引擎**: [Three.js](https://threejs.org/) - 打造真實感流體與器材互動。
- **2D UI**: [PixiJS](https://pixijs.com/) - 提供流暢的高性能繪圖介面。
- **開發框架**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/) - 現代化、極速的構建與組件管理。
- **參數調度**: [Tweakpane](https://cocopon.github.io/tweakpane/) - 專業級參數微調面板。
- **語言**: [TypeScript](https://www.typescriptlang.org/) - 嚴謹、穩定的代碼品質。

## 🚀 開始使用

### 🌐 Demo 網址
立即體驗：[https://alvin999.github.io/3-gold-brew/](https://alvin999.github.io/3-gold-brew/)

### 環境需求
- [Node.js](https://nodejs.org/) (建議 v18 以上)
- npm 或 yarn

### 安裝步驟

1.  **克隆專案**
    ```bash
    git clone https://github.com/alvin999/3-gold-brew.git
    cd 3-gold-brew
    ```

2.  **安裝依賴**
    ```bash
    npm install
    ```

3.  **啟動開發伺服器**
    ```bash
    npm run dev
    ```

4.  **開啟瀏覽器**
    造訪終端機顯示的網址（通常為 `http://localhost:<PORT>`）即可開始您的金沖煮訓練之旅。
